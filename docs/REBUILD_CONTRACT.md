# v4 重建约定

本文件以用户 2026-10-09 确认的规则为准，取代此前方案中冲突的建议。

- 重写核心和全部可见网页。平台代码仅作为执行适配使用，不代理旧 HTML，不保留第二套完整设置页。
- 五个平台均有工作区开关，默认仅 Telegram、小红书开启。只处理新下载，不检查或转换历史媒体。
- 导入旧下载记录；采集检查点与下载成功分开。首次运行正常处理内容，按连续已下载作品停止，默认 X 10、Pixiv 20、抖音 50；后续保留来源边界/上游终止信号/指定标记。只读已有记录，不扫描历史归档；抖音仅对本次上游提交的准确文件路径判断已存在。分钟上限是抖音/X/Pixiv 的独立兜底，超限标记未完成，不能当成功。
- 工作区自动处理后入库，无暂停。不可用则 bypass。转换自动重试一次，再失败则使用有效原件入库。
- 视频使用 N95 核显 HEVC 编码，高画质，保持尺寸/帧率，不采用 CPU 编码兜底。已有 HEVC 不重复编码。封装/流信息及少量首尾片段验证，不全长解码。转换成品更大或一样大则丢弃成品，归档原件。
- PNG 转 quality=95 JPEG，保持尺寸；实际透明或动画 PNG 保留原件；成品不更小保留 PNG。其他图片原样归档。
- 最终文件校验、无覆盖入库、持久记录完成后删除工作区原件；转换失败不能导致原件被删除。
- 同时仅一个媒体转换，硬解/硬编优先、输入节流、低 CPU/I/O 优先级。工作区放在媒体同一卷。
- 单用户，默认无密码且认证关闭；设置可添加密码并开关认证。
- 默认短日志，完整日志可分页查看和下载。默认不在首页堆日志。
- 首页自动检查上游候选版本，区别已安装 commit/版本与上游候选，不自动升级。
- 正式数据/session 只由一个生产实例使用。新版本在隔离数据与端口验证后提供可审查结果，再做正式切换。
